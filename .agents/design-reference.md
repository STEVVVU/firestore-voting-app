# Course voting screen reference

Source: [Pitt CS 1660 course template](https://github.com/pitt-cs-1660/spring2025-cs1660-cloud-run-cc-cloud-run/blob/main/template/index.html). Locally rendered the original Jinja template with sample 3–2 totals and one vote, served on loopback, and visually inspected with CUA Chrome at a 2560 × 1431 screenshot. Reference source and rendered sample are retained as `evidence/course-template.html` and `evidence/course-rendered.html`; browser screenshot was visible in the tool output but the CUA API did not provide a documented screenshot-to-file operation.

Observed layout: dark teal 64 px header with centered white title and left login button, pale yellow background, centered heading, two wide side-by-side panels, teal-tinted leader panel, large symbols and vote counts, centered teal actions, then a narrow centered recent-vote collection. The implementation uses the same public Materialize 1.0.0 stylesheet and independent HTML/JS. UTF-8 is declared to correct the mojibake seen when the course source was rendered. Explicit disabled controls and a configuration notice differ because the course demo had no working local identity. Recent rows omit identity details. Compared the local screen in CUA Chrome at the same 2560 × 1431 screenshot size with synthetic 3–2 data; hierarchy, widths, colors, and panel positions correspond. The configuration notice adds vertical space; row details and symbol rendering vary. A narrow screenshot, configured sign-in, and an interaction-driven browser vote remain unverified.
